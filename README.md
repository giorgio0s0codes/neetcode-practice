# NeetCode Practice

My solutions to the [NeetCode](https://neetcode.io/practice) problems, written in Python.

## Structure

Each topic from the NeetCode roadmap gets its own folder. Each problem is one file named after its LeetCode number and title:

```
arrays-and-hashing/
  0001_two_sum.py
  0049_group_anagrams.py
two-pointers/
  0125_valid_palindrome.py
```

A starting template for new problems is in [template.py](template.py).
